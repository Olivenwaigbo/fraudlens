# FraudLens

## Payment Fraud Detection & Risk Intelligence

FraudLens is an experimental payment risk intelligence platform that analyzes synthetic payment transactions to identify suspicious behavioral patterns, generate risk signals, and support human investigation.

The project combines:

- Behavioral feature engineering
- Rule-based risk detection
- Anomaly detection
- Supervised machine learning
- Risk scoring
- AI-assisted investigation
- Interactive data visualization

## Important Boundary

FraudLens uses synthetic data.

It is not a payment processor, does not process real money, and does not autonomously determine whether a transaction is fraudulent.

The system is designed as an investigation and decision-support prototype.
